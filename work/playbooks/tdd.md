# TDD

For building code test-first, on the user's explicit request. TDD wraps Implement: copy Implement's steps as usual and run the three below where each one says. Fix is already test-first and needs no mode. Behavior a local test cannot drive, such as infrastructure observable only once deployed, stays on plain Implement and gets its post-deploy check named for Deploy.

1. **Agree the seams** (replaces the red half of Implement step 3: write the criteria, but make each one red only in its own slice). A seam is a public interface where a caller observes behavior: a function or module API, an endpoint, a CLI, a rendered output. List the seams and the behaviors each must show, riskiest first. When the spec or plan does not name the seams, confirm the list with the user once before the first test; tests land only at agreed seams. Done when every criterion maps to a behavior at a seam.
2. **Loop in vertical slices** (runs Implement step 6 one slice at a time). One slice is one behavior at one seam: write its test, run it red for the expected reason, write the least code that turns it green, then rerun every slice so far. Each slice is a tracer bullet; the next one answers to what this one taught, so tests are written one at a time, each just ahead of the code it drives. Tests follow **[test-behavior-not-implementation](../principles/test-behavior-not-implementation/SKILL.md)**. Replace only what lies outside the code: external services, time, randomness, and a database or file system when a real local one is impractical; your own modules run for real. Pass each external dependency in rather than building it inside, and give each external operation its own function, so each mock returns one shape without branching. Log each red and each green as evidence. Done when every agreed behavior has a green slice.
3. **Refactor under green** (before Implement step 7). With all slices green, reshape what the loop left awkward: duplication, names, structure. The tests stay unchanged and green after each change. Done when the code reads cleanly and the tests are green and unmodified since the last slice.

**Reply.** Implement's reply, plus each slice with its seam and its red and green results.
