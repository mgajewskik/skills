# Change

The deliverable is a local, reviewed, verified change to infrastructure source, ready to roll out. Only the files the user asked about change. Nothing is applied, initialized against a real backend, installed, or deployed here; rollout is the Deploy playbook.

1. **Record the baseline.** Working tree status, pre-existing staged and unstaged edits, and the scoped files' current content. Name the files you own and preserve everything else. Done when you can tell your diff apart from anyone else's.
2. **Read the contract around the target.** Producers, consumers, overrides, generated outputs, existing checks, and installed tool versions (**[ground-claims-in-the-environment](../principles/ground-claims-in-the-environment/SKILL.md)**). Read any validator, renderer, or hook before running it; a local checkout can still call remote backends, through whatever identity is active (**[infra-act-through-the-narrowest-identity](../principles/infra-act-through-the-narrowest-identity/SKILL.md)**). Done when every check you plan to run is classified as local-only or as a read-only remote call.
3. **Write criteria and make them red.** Binary criteria and anti-criteria, including one that catches a misleading pass (schema-valid but semantically wrong) (**[test-behavior-not-implementation](../principles/test-behavior-not-implementation/SKILL.md)**). For a defect, reproduce it with a saved fixture or deterministic local render first. Done when the check fails on the current source for the reason you expect.
4. **Name the shape.** Environment identity, resource ownership, inputs and overrides, allowed states. Resolve each decision in one place (**[model-the-domain](../principles/model-the-domain/SKILL.md)**). Stateful resources declare their guards in source: deletion protection or `prevent_destroy`, retention, backups that a destroy of this stack cannot reach, and state in a locked shared backend (**[infra-act-through-the-narrowest-identity](../principles/infra-act-through-the-narrowest-identity/SKILL.md)**, **[infra-design-recovery-first](../principles/infra-design-recovery-first/SKILL.md)**); report a missing guard as a finding. Retry logic you write retries only transient errors, with backoff, jitter, and a cap, at one layer. For a novel consequential design, compare two or three genuinely different sketches (**[exhaust-the-design-space](../principles/exhaust-the-design-space/SKILL.md)**); for a mechanical edit, follow the existing pattern.
5. **Make the smallest correct change** (**[laziness-protocol](../principles/laziness-protocol/SKILL.md)**). Subtract what this change makes obsolete in source (**[subtract-before-you-add](../principles/subtract-before-you-add/SKILL.md)**); keep compatibility paths and operational comments whose consumers you have not inventoried (**[infra-preserve-compatible-transitions](../principles/infra-preserve-compatible-transitions/SKILL.md)**). For a refactor, pin the rendered output first and require it byte-identical afterwards.
6. **Verify offline in units.** Inspect the actual rendered or generated output against an independently derived expectation (**[prove-it-works](../principles/prove-it-works/SKILL.md)**). Exercise an accepted input, a rejected input, and the plausible wrong result. For generators, run twice and from a partial state (**[make-operations-idempotent](../principles/make-operations-idempotent/SKILL.md)**). Log each check as evidence; a skipped or unavailable check is `unverified`. Done when every criterion is green or explicitly unverified with the reason.
7. **Independent review** for significant behavior, security or permission, data, deployment, or agent-rule changes. The reviewer gets criteria, anti-criteria, all scoped paths, and evidence pointers, not your conclusion. Done on `Decision: PASS` or an explicit user waiver.

**Reply.** Changed files, criteria and anti-criteria status, checks actually run, review verdict, and what remains unproven at runtime. Rollout goes to Deploy with this artifact's revision.
